# Specification

The normative text this repository implements.

- `agentic-control-architecture-v1.0.md` — the specification (v1.0, internal 1.17): body sections 0–11, appendices A (component contracts), B (run states, resolvers), C (hosting), D (evidence schema).
- `agentic-control-architecture-rationale-v1.0.md` — the design rationale: core decisions, ADR-1…ADR-26, traceability, the sixteen-round verification record, known weaknesses.
- `deferred-to-v1.1.md` — items the verification rounds recommended and the author deferred.

The files are the pre-deposit text and still carry the author's placeholders (title, short name, dates, author, URL). Prose is published under CC0 1.0; the code in this repository is Apache-2.0.

Where the code and this text disagree, the text wins. `../docs/spec-map.md` maps clauses to modules and tests.
